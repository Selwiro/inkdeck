纸屏牌组

为墨水屏重做的本地优先背诵客户端。把 .apkg 放进设备，分页浏览、按官方调度复习、查看统计；0.1.0 无账号、无网络权限、无广告与埋点，学习记录只留在本机，二期接入 AnkiWeb 官方同步。

界面截图

0.1.0 构建在墨案 InkPad X 上的实机画面，牌组为演示数据；界面会随版本迭代调整。

功能

  • 本地导入：选择或分享 .apkg，包内图片与音频一并入库；失败回滚，不留半套牌组。
  • 分页浏览：牌组与卡片按屏高固定每页条数，底部翻页条，不做无限滚动。
  • 四档评分：重来 / 困难 / 良好 / 容易，间隔由 rslib 按牌组原有调度计算；音量键可翻面与评分。
  • 整卡渲染：支持常见 HTML 子集、图片等比缩放与音频播放，题答分隔线按墨水屏对比度调整。
  • 今日统计：复习数、正确率、用时、到期量与卡片构成，两页翻完。
  • 三种语言：English / 简体中文 / 繁體中文，默认跟随系统，也可在设置页固定。

为墨水屏而做

  • 无动画、无涟漪、无加载动画，翻卡与切换整页重绘。
  • 固定白底黑字，高对比度，不依赖彩色与阴影。
  • 分页替代滚动，避免长列表与嵌套滚动。
  • 正文不小于 18sp，字号 18 / 22 / 26 三档，控件同步放大。
  • 点击目标不小于 48dp，主要操作在单手可达区。
  • 可手动整屏刷新清残影；策略与设备差异记录在仓库文档里。

隐私

0.1.0 不申请网络权限，没有账号体系，没有广告、统计 SDK 或崩溃上报。牌组、媒体与学习记录只写入应用私有目录；卸载即删除。二期接入 AnkiWeb 官方同步后才会申请网络访问与 AnkiWeb 账号。

导入的牌组内容来自你自己的文件，0.1.0 不会上传任何数据；二期的 AnkiWeb 同步由你主动开启。

下载

0.1.0 是测试版（pre-release），按 ABI 拆分为两个包，按设备任选其一；签名一致，可覆盖升级。发布包与校验文件都在 GitHub Releases。
