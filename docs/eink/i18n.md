# 多语言与系统语言跟随

更新：2026-11-18。目标：UI 文案全部走 Android 资源，默认跟随系统语言；当前提供英文与简体中文。

## 资源结构

| 文件 | 语言 | 说明 |
|---|---|---|
| `app/src/main/res/values/strings.xml` | 英文（默认） | 系统为其它语言时的回退 |
| `app/src/main/res/values-zh/strings.xml` | 简体中文 | 系统 zh-Hans/zh-CN 等 |
| `app/src/main/res/values-b+zh+Hant/strings.xml` | 繁體中文 | 用 **script** 限定符 `b+zh+Hant`，不用 `zh-rTW`，覆盖所有繁体地区 |

- `app_name`：英文 `Inkdeck`，中文 `纸屏牌组`；启动器名称随系统语言变化。
- 所有页面文案（牌组/卡片/学习/统计/设置/导入/媒体缺失/错误提示）都通过 `stringResource(R.string...)` 或
  `Context.getString(...)` 读取，不再在 Compose 里硬编码中文。
- 后端（rslib）的 `preferred_langs` 也取自 `Locale.getDefault()`：
  `[locale.toLanguageTag(), locale.language, "en"]`，卡片里的后端提示与 Fluent 文案跟随系统。
- 用户牌组名、卡片字段等**数据**不翻译；这是 Anki 内容本身。

## 应用内语言设置

设置页「语言 / Language」提供三项：

| 选项 | 行为 |
|---|---|
| 跟随系统 / System | 默认；读系统 locale |
| 简体中文 | 固定 `values-zh` |
| 繁體中文 | 固定 `values-b+zh+Hant`（script 限定符，不依赖 zh-TW） |
| English | 固定 `values` |

- 存放在 `inkdeck_settings` 的 `language_tag`（`system`/`en`/`zh`）。
- `MainActivity.attachBaseContext()` 用 `AppLocale.wrap()` 包一层 Configuration；
  切换后 `recreate()` 立即生效，重启仍保持。
- `Locale.setDefault()` 同步设置，rslib 的 `preferred_langs` 会跟随；
  切换语言时 `AnkiRepository.restartBackend()` 关闭并重开后端，使后端文案也切换。
- 系统语言变化只影响「跟随系统」选项；固定语言时不受系统变化影响。
- 启动器名称由系统 locale 决定，不随应用内覆盖实时变化。

## 新增语言

1. 新建 `res/values-<tag>/strings.xml`，复制 `values/strings.xml` 并翻译。
2. 在 `AppLocale` 的 `TAGS` 和设置页语言选项中增加该 tag；`stringResource` 自动选择。
   繁体中文请用 `values-b+zh+Hant`，不要用 `values-zh-rTW` 代表整个繁体。
3. 若后端要完整本地化，确认 rslib 的 Fluent 目录包含该语言；否则回落到英文。

## 验证

```sh
# 英文
adb shell settings put system system_locales en-US
adb shell am force-stop ink.inkdeck && adb shell am start -n ink.inkdeck/.MainActivity

# 中文
adb shell settings put system system_locales zh-CN
adb shell am force-stop ink.inkdeck && adb shell am start -n ink.inkdeck/.MainActivity
```

2026-11-18 模拟器实测：英文下首页标题 `Inkdeck`、标签 `Decks/Import/Stats/Settings`、统计
`Reviewed today/Correct today/Upcoming`、设置 `Font size/Contrast/Standard/Soft/Softer` 均正确；
中文下维持「纸屏牌组/牌组/导入/统计/设置」。

## 注意

- `values/strings.xml` 是回退语言，新增 key 必须先加到该文件，否则编译期 `R` 不存在。
- 带 `%1$d`/`%1$s` 的字符串保持参数顺序；翻译时可调整语序但不能丢占位符。
- 不再使用 `SettingsStore.CONTRAST_LABELS` 这类硬编码中文列表，对比度标签已移到资源。
