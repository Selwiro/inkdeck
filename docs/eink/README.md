# 墨水屏设计基线

面向所有 Android 8.0+ 墨水屏设备，不绑定单一型号。硬性规则见 [AGENTS.md](../../../AGENTS.md)，本文记录落地方式与验证方法。

## 视觉

- **只有纸色与墨色两个值**：`#000000` / `#FFFFFF`。不使用灰阶、半透明、阴影与渐变——墨水屏上会抖动成噪点或糊成一片。
- **固定白底黑字**；2026-11-18 起移除反色/配色切换。
- **正文不小于 18sp**，标题可用大字号与加粗强化层级；默认字号按屏宽分档（`<600` / `600–839` / `840–1199` / `≥1200dp` → 18/22/26/26sp），设置页 18/22/26sp 三档可手动覆盖，卡片正文的 CSS px 也按比例缩放。
- 字体使用系统字体或内置开源字体，不嵌入商用字体。
- UI 文案走 Android 资源，默认跟随系统语言（英文/简体中文），见 [i18n.md](i18n.md)。

## 交互

- **无动画、无涟漪、无 Spinner**：`Theme.Inkdeck` 关闭窗口动画与 Activity 过渡；按钮用描边 + 无 indication 的 `clickable`。
- **点击目标不小于 48dp**，主要操作放在单手可达区（下半屏）。
- 支持音量键翻卡/评分：牌组/卡片/统计页用音量键翻页，学习页音量下翻面或「良好」、音量上加「重来」；按键由页面消费，到边界不漏给系统音量面板，长按重复事件被忽略。
- 不用平滑滚动与嵌套滚动：分页或整屏重绘替代。

## 刷新

- 翻卡与页面切换整屏重绘，避免局部刷新造成闪动。
- 残影累积到阈值时主动触发全屏刷新。标准 Android 没有公开的 EPD 刷新 API，只能尽量用「整屏重绘 + 短暂纯色过渡」；厂商私有接口是否接入见 README「待决定」。
- 每次调整刷新策略，都要在本文「验证记录」里补一条。
- 真机结论见 [device-inkpad-x.md](device-inkpad-x.md)：整屏刷新可用；后续按用户决定移除了反色，固定白底黑字。

## 落地位置

| 规则 | 代码位置 |
|---|---|
| 关闭窗口动画 | `app/src/main/res/values/themes.xml` |
| 纸色/墨色 | `app/src/main/res/values/colors.xml`、`ui/InkTheme.kt` |
| 无涟漪按钮、48dp 触控 | `ui/InkComponents.kt`、`ui/InkLayout.kt` |
| 字号下限 18sp、无动画组件 | `ui/InkComponents.kt`、`ui/InkLayout.kt` |
| 默认字号按屏宽分档 | `ui/InkWidthClass.kt`、`data/SettingsStore.kt`、`MainActivity.onCreate` |
| 统一顶栏、底部导航、列表/指标 | `ui/InkLayout.kt`（见 [layout.md](layout.md)） |

## 尺寸基线

版式按 **dp 宽度**分档，不按英寸：手机形态 408–436dp、6 寸 571–576dp、7.8–8 寸 749–768dp、
10 寸 906–989dp、13.3 寸 1277dp。各机型的分辨率/ppi/dp、`wm size` 与 `wm density` 复现命令、
四档宽度下的实测截图见 [devices.md](devices.md)。
