# 牌组与卡片浏览

实测：2026-11-17 初版，2026-11-18 按 T017 全应用版式重排；AVD `milenote`
（Android 14 / API 34，1080×2400，420dpi → 密度 2.625）。
本文记录浏览页的墨水屏版式、翻页策略与模拟器观察；真机项留空待 T010。

## 版式参数

| 项 | 值 | 说明 |
|---|---|---|
| 页边距 | 20dp | 顶栏/正文/底部导航共用 |
| 顶栏 | 最小 64dp，标题 22sp、副标题 14sp | 二级页左侧 48dp 返回箭头 |
| 底部导航 | 60dp | 牌组 / 导入 / 统计 / 设置，选中项 3dp 下划线 |
| 每屏条目 | 牌组 6 行 / 卡片 6 行；26sp 时 5 行 | 固定条目 + 分页，不做滚动 |
| 列表行高 | 最小 **64dp** | 底部 1dp 分隔线 |
| 主操作按钮 | **52dp** 实心墨底或 1dp 细框 | 一页最多一个；学习页「显示答案」用细框 |
| 四档评分 | **64dp** | 四段相连、只有内部 1dp 竖线；左右/底部不画线 |
| 次要按钮/菜单 | 48dp 细框或纯文字 | 1dp 描边，不再满框 2dp |
| 正文字号 | 18 / 22 / 26sp 三档 | 全球 `LocalInkBodySize`；标题/菜单/按钮按 body/18 同步缩放 |
| 翻页控件 | 底部 `PagerBar`：‹ 上一页 / `x / y` / 下一页 › | 只有一页时整条隐藏 |
| 进度提示 | 纯文本（"正在读取卡片…"） | 无 Spinner、无进度条动画 |

## 学习入口

- **点牌组直接进入学习模式**（与 AnkiDroid 一致）：后端队列是「当前牌组」的队列，
  进入前先 `DecksService.SetCurrentDeck`，再 `SchedulerService.GetQueuedCards`；
  不切牌组直接取队列会一直拿到 Default 的 0 张。
- 卡片列表不再作为牌组的第一跳：学习页顶栏右上角的「卡片列表」按钮进入，返回时回到学习页。
- 学习页 / 浏览页都不显示内部卡片编号，也不写「问题 / 答案」标题；
  顶部只保留牌组名与队列余量。
- 学习页底部只有一条学习操作：问题面「显示答案」或答案面四档评分，左右贯通、底部贴底、
  左右和底部都不留线；操作区上方只保留一条 1dp 分隔线；
  返回牌组由顶栏左侧的 48dp 返回箭头承担，「卡片列表」在顶栏右上角。
  设置和字号只在顶层「设置」页，不再放进卡片页。
- 顶层页（牌组/导入/统计/设置）统一顶栏 + 底部导航；学习页/卡片页不显示全局导航。
- 卡片页正文用 `InkPageScaffold`，正文是唯一的 `weight(1f)` 子项，吃掉剩余高度；
  此前正文之外还有一个 `Spacer(weight(1f))`，两者平分高度，长卡会只显示一半。

## 翻页策略

- 整页重绘：页码是 `mutableIntStateOf`，翻页时把新的 6 条数据整体替换，Compose 重组整屏；
  没有滚动、没有过渡动画、没有涟漪（`clickable` 传 `indication = null`）。
- 翻页入口有两个：底部按钮，以及**音量键**（下 = 下一页，上 = 上一页）。
- 音量键由当前页面消费：到第一页/最后一页也返回 `true`，不再漏给系统弹出音量面板；
  长按产生的重复事件只消费不执行。
- 页码由 `MainViewModel` 持有：从学习页/卡片页返回时保持原来的牌组页与卡片页。
  硬件键通过 `HardwareKeys` 全局路由，只由当前页面注册，离开页面即清空。
- 数据侧一次只取一页：仓库层先 `SearchCards` 拿 id 列表，再对当前页的 6 个 id 逐个
  `GetCard` + `RenderExistingCard`；UI 不持有整副牌，500 张以上内存也平稳。
- 卡片列表的标题改用**笔记第一个字段**（`NotesService.GetNote` 的 `fields[0]`，再经 `htmlToPreview` 去标签），
  不再把「牌组名 + Vocabulary」重复贴在每一行；点进去看整张卡。列表页不再逐张
  `RenderExistingCard`，只取首字段，翻页明显更快。

## 卡片正文

列表只显示笔记首字段的纯文本；**点进去的卡片正文改为 HTML/CSS 子集渲染**，
见 [card-rendering.md](card-rendering.md)。此前正文也复用预览函数，导致结构化卡片被压成一整段。

## 媒体显示

- 图片：`<img src="...">` 里取文件名 → 直接读 `collection.media/<name>` → `BitmapFactory` 解码 →
  Compose `Image`（`ContentScale.Fit`，最高 360dp）。
- 音频：`[sound:...]` 取文件名 → `MediaPlayer` 的 48dp ▶ 方块按钮；文件缺失时显示「（缺音频：xxx）」。
- 已知取舍：只做「看得见、听得到」，不渲染模板 CSS/JS；复杂排版与 TTS 后续再说。

## 模拟器观察

| 操作 | 结果 |
|---|---|
| 牌组列表（8 个牌组） | `1 / 2`，第 2 页显示最后 2 个；音量键下/上翻页均生效 |
| 卡片列表（20 张） | `1 / 4`，每页 6 张；音量键翻页正常 |
| 点牌组（2026-11-18） | 直接进入该牌组学习页，余量从该牌组取；不再先到卡片列表 |
| 顶层导航（2026-11-18） | 牌组 / 导入 / 统计 / 设置四项可互相切换，选中项下方有 3dp 墨线 |
| 卡片列表（2026-11-18） | 标题为笔记首字段（hog/pitcher…），每行 64dp、1dp 分隔线；单页时隐藏分页条 |
| 学习页顶栏 | 右上角「卡片列表」可点；左侧返回箭头回牌组；底部只有学习操作条 |
| 卡片页长答案 | 正文吃满剩余高度，示例列表与引用完整显示，可单层滚动 |
| 打开带图卡片 | 图片按原比例显示（黑框 + 黑条测试图），点击「显示答案」后出现答案文本 |
| 打开带音频卡片 | 出现 48dp ▶ 方块按钮，点击无崩溃（模拟器无音频输出，未验证出声） |
| 字号 26sp | 5 行牌组 + 分页条 + 底部导航仍在一屏内，无破版；`hog` 卡正文行高由 55px 变 190px；重启后保持 26sp |
| 第 2 页打开牌组再返回（2026-11-18） | 仍停在第 2 页；卡片列表第 2 页打开卡片再返回同样保持 |
| 音量键到边界/长按（2026-11-18） | 第 1/最后 1 页及学习页均不弹系统音量面板；长按只执行一次，不连续评分 |
| 缺失媒体 | 未构造（代码路径会显示「（缺图/缺音频：…）」） |

## 可复用代码

- 分页条与列表行：`ui/InkPager.kt`（`PagerBar` / `InkRow`）
- 硬件键路由：`ui/HardwareKeys.kt`
- 翻页实现：`ui/DeckListScreen.kt`、`ui/CardListScreen.kt`
- 统一页框 / 顶栏 / 底部导航 / 列表行：`ui/InkLayout.kt`（`InkPageScaffold` / `InkTopBar` / `InkNavBar` / `InkListRow`）
- 版式规范与踩坑：`docs/eink/layout.md`
- 学习页 / 浏览页：`ui/ReviewScreen.kt`、`ui/CardDetailScreen.kt`
- 按牌组取学习队列：`data/AnkiRepository.reviewQueue(deckId)`
- 分页数据：`data/AnkiRepository.cardsPage()`、`data/CardContent.kt`
- 字号全局生效：`ui/InkTheme.kt` 的 `LocalInkBodySize`

## 待真机确认

1. 墨水屏整屏刷新时翻页是否残留上一页残影（模拟器看不出）。
2. 音量键在阅读器硬件上的键值（部分国产墨水屏把音量键映射成翻页键，键值可能是 PAGE_UP/DOWN）。

4. 26sp 在 6 寸小屏上是否需要降到 5 行/屏。

## InkPad X 真机补充（2026-11-18）

- 1200×1600 / 212dpi：18sp 每页 6 个牌组、26sp 每页 5 个；牌组/卡片列表无裁切。
- 音量键下/上翻页在牌组、卡片列表、统计页均生效；到边界不弹系统音量面板。
- 卡片列表 20 张 / 4 页，音量键翻页正常；点卡片进入浏览后可返回列表。
- 26sp 下正文明显放大（用户确认合适）；长标题两行截断，未把分页条挤出屏幕。
