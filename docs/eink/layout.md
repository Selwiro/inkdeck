# 全应用版式：统一顶栏 + 底部导航

更新：2026-11-18。此前各页各自决定边距、标题字号和按钮描边：首页 32sp 标题 + 24dp 边距 +
四个满框大按钮，统计页 30sp 标题 + 满宽「返回」，设置页 28sp 标题 + 另一种按钮，
卡片页又是 20sp 标题 + 18dp 边距。放在一起看就是「每页都像不同应用」。

本文记录重排后的统一版式，可直接被后续 eink 项目复用。

## 设计令牌

| 项 | 值 | 说明 |
|---|---|---|
| 页边距 | 20dp | 左右一致；顶部内容从顶栏下方开始 |
| 顶栏最小高度 | 64dp × 字号系数 | 标题 22sp、副标题 14sp（均按 18sp 基准缩放） |
| 正文 | 18sp 起 | 跟随设置页三档；标题/菜单/按钮/行高/留白按 body/18 同步放大（18sp 为原版式） |
| 辅助信息 | 14sp | 副标题、说明、统计标签（随字号缩放） |
| 列表行 | 最小 64dp | 底部 1dp 分隔线；点击区整行 |
| 底部导航 | 60dp | 四项等宽，选中项文字加粗 + 下方 3dp 墨线 |
| 四档评分条 | 64dp | 无外框，只有内部 1dp 竖线；四段相连，顶部由操作区的一条分隔线收口 |
| 底部操作区 | 56/64dp | 「显示答案」/ 四档评分左右贯通、底部贴底；不画左右和底部边框 |
| 触控 | ≥ 48dp | 返回箭头、分页、菜单项都单独给 48dp |
| 描边 | 1dp | 只有次要按钮/未选中项用细框；不再满屏 2dp 粗框 |

**默认字号按窗口宽度分档**（`ui/InkWidthClass.kt`）：`< 600` / `600–839` / `840–1199` /
`≥ 1200dp` → 18 / 22 / 26 / 26sp。只在用户没手动选过字号时生效；设置页三档一旦选择就写入
`SharedPreferences`，换宽度、重启都不再被默认值覆盖。

## 页面类型

**顶层页**（牌组 / 导入 / 统计 / 设置）：`InkPageScaffold` + `InkNavBar`。
没有返回按钮，底部四项互相切换；Android 返回键回牌组。

**二级页**（学习 / 卡片列表 / 卡片浏览）：顶栏左侧返回箭头，不显示全局导航。
学习页右上角是「卡片列表」按钮；底部只有一条操作区（显示答案 / 四档评分 / 回到问题），
左右贯通、底部贴底，不画左右和底部边框；只有操作区上方一条 1dp 分隔线。
设置和字号只在顶层「设置」页里，不再出现在卡片页。

## 系统栏

`MainActivity` 用 `WindowCompat.setDecorFitsSystemWindows(window, false)` +
`Modifier.windowInsetsPadding(WindowInsets.safeDrawing)` 统一处理状态栏/导航栏/刘海，
页面内容不会钻到状态栏下面（此前真机上标题与状态栏重叠）。

状态栏跟随纸色/墨色：`MainActivity` 在 `LaunchedEffect(settings.inverted)` 里设置
`window.statusBarColor` 和 `WindowCompat.getInsetsController(...).isAppearanceLightStatusBars`，
白底时深色图标、黑底时浅色图标，避免顶部留一条系统灰带。系统底部导航栏保持黑色。

## 列表与统计

- 牌组行：左侧缩进 16dp/层级（不再用全角空格撑缩进），名称 20sp，下面 14sp「新/学/复」，
  右侧大数字 + 「待学」两行。
- 卡片列表：标题用笔记第一个字段（`NotesService.GetNote` 的 `fields[0]`），
  不再每行重复「牌组名 + Vocabulary」；20sp、最多两行、右侧 `›`。
- 分页：一页时隐藏整条；多页时「‹ 上一页 / x / y / 下一页 ›」，纯文字 48dp 触控。
- 统计：2×2 指标网格用 1dp 细线分隔，不用四张卡片框；下方键值行。

## 踩过的坑

### 底部菜单的 `fillMaxHeight` 把整页撑坏（历史）

早期底部菜单 `InkBottomMenu` 写成 `Row(heightIn(min = 56.dp))`，菜单项用 `Modifier.weight(1f).fillMaxHeight()`；
该菜单现已按反馈移除，但这个坑仍适用于任何「heightIn(min) + fillMaxHeight」的组合。
Row 没有固定高度时，`fillMaxHeight` 会把子项撑到父级剩余高度，Row 随之吃满整屏：
底部操作区跑到顶部、正文被挤成 0 高、菜单文字垂直居中在屏幕中间。

修法：菜单 Row 用**固定** `height(56.dp)`，子项再 `fillMaxHeight()` 就只填这 56dp。
教训：`heightIn(min=...)` 只给下限，不限制上限；只要子项里有 `fillMaxHeight`，就必须给父级固定高度。

### 显示答案不要整块黑底

学习页最初的「显示答案」是实心墨底主按钮，整屏只有一个大黑块，和 AnkiDroid 的观感差很多。
现在改成无外框的整宽文字操作（`InkBarAction`）；四档评分改成四条相连的分段，只保留内部竖线，
顶部由操作区的一条分隔线收口，左右和底部都不再画线。

### 满框按钮没有层级

旧版所有按钮都是 2dp 满框，一屏出现 4~6 个同等重量的黑框，用户不知道先点哪个。
现在分三层：主操作实心墨底（一页一个）→ 次操作 1dp 细框 → 导航/分页纯文字 + 选中下划线。

### 卡片列表重复牌组名

卡片渲染出的问题面开头通常带「牌组全名 + Vocabulary/Definition」；直接拿来当列表预览，
每一行都以相同字样开头，列表看上去像一堆重复文本。改用笔记首字段做标题后，
列表变成 hog / pitcher / sneaker / shriek / runt，扫读成本明显下降。

## 验证

- 模拟器 AVD `milenote`（API 34，1080×2400，420dpi）：
  - 18sp 与 26sp 下，牌组、卡片列表、学习页、卡片浏览、统计两页、设置、导入均无裁切/重叠；
  - 顶层四页底部导航可互相切换；学习页/浏览页隐藏导航；
  - 学习页右上「卡片列表」可点；底部显示答案 / 四档评分左右贯通、底部贴底、无左右/底部边框；
  - 设置选中项实心、统计 2×2 指标、卡片列表单词标题在三档字号下都可读。
- JVM 单测与 instrumentation 结果见任务记录 T017。

## 真机确认（InkPad X）

- 1dp 分隔线与 3dp 选中下划线在 10 英寸 212dpi 上清晰；26sp 下无裁切。
- 底部导航 60dp 在 906×1208dp 上点击正常；6 寸小屏用模拟器 572dp 验证不裁切（见 [devices.md](devices.md)），真机仍未验证。
- 26sp 统计两页仍在一屏内，无需再压缩行高；用户确认 26sp 阅读合适。
- 2026-11-18 按用户反馈移除反色/配色，固定白底黑字；大字号下顶栏、菜单、按钮、行高同步放大。
- 详细记录与截图见 [device-inkpad-x.md](device-inkpad-x.md)。
