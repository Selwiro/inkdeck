# 启动图标

用纯黑描边勾出闪卡轮廓，卡面留白，方形白底铺满画布。在 128 单位坐标系中，卡片轮廓和卡面短线统一使用矢量线宽，但缩放后锁定视觉线宽约 1.5 单位。双卡图案按画布 **82.5%** 放置——取原 65% 与放大 100% 的中间值，实机图案约占框宽 63%。

参考墨案桌面截图：带框的浏览器/邮件/文件管理器/计算器等图标，图案外接框约占图标框宽的 71%–83%。本图标不再缩在中间，也不像 100% 版那样贴边。

**线宽锁定**：0.65 版的有效线宽为 `2.3 × 0.65 = 1.495`；82.5% 版把矢量 `strokeWidth` 设为 `1.5 / 0.825 ≈ 1.818`，缩放后仍是约 **1.5 单位**，不随图案缩放变粗。

对墨案桌面截图中的文件管理器、计算器和电子邮件图标，沿直线的垂直方向统计灰阶覆盖，得到约 1.6–2.1 px 的笔画线宽。用同一截图中旧版图标的线宽推算桌面显示比例，再按该比例渲染新版核对，黑色笔画约为 1.9 px。

用 `./gradlew :app:assembleDebug` 构建后检查 APK 中的自适应图标线宽。2026-11-18 在 InkPad X 桌面复核：图案占比、线宽与相邻图标一致；圆形遮罩的极限裁切需在其它启动器上复核。

Android 矢量资源位置和导出方式见[图标打包说明](../build/packaging.md#图标)。
