## 真机发现

### 1. 导入在 Android 上默认写入 `/data/local/tmp`（已修复）

首次导入报：

```
IO_ERROR: Failed to create file in '/data/local/tmp':
Permission denied (os error 13) at path "/data/local/tmp/.tmpXxhpjU"
```

原因：rslib 用 Rust `std::env::temp_dir()`，Android 上默认落到 `/data/local/tmp`，普通应用不可写。
修复：新增 JNI `NativeBridge.setTempDir()`，在后端线程 `AnkiBackend.open()` 里把
`TMPDIR`/`TMP`/`TEMP` 指向 `cache/rslib-tmp`，再 `openBackend`。修复后同一包导入成功，
重复导入也正常。代码位置：`rslib/bridge/src/lib.rs`、`rslib/NativeBridge.kt`、
`rslib/AnkiBackend.kt`、`data/AnkiRepository.kt`。

复现：未修复版在 InkPad X 上用文件管理器分享任意 `.apkg`，导入结果页显示上述 IO 错误；
修复版重新导入即成功。

### 2. 反色/配色已移除（2026-11-18 后续反馈）

真机验收时发现反色模式下墨案系统顶栏仍为白色；随后用户决定直接移除配色/反色，
固定白底黑字，因此不再需要系统顶栏适配任务。设置页的选中项也改为粗框 + 圆点 + 加粗，
不再黑底反白。

### 3. 整屏刷新可用

浅色模式下点「立即整屏刷新（清残影）」时，用户确认屏幕闪黑并清掉残影；screenrecord
逐帧检查为约 150ms 的黑色帧。该策略只使用标准 Android API，未调用 Swtcon/厂商私有接口。

### 4. 字号与版式

26sp 在 10 英寸上被用户确认「合适」；牌组行、学习页正文、统计页均无裁切。26sp 下
每页从 6 条降为 5 条，仍保留底部导航和分页条。

## 复现步骤

1. `adb install -r app-armeabi-v7a-release.apk`，启动。
2. 导入：文件管理器分享 `.apkg`，或「导入 → 选择 .apkg 文件」；确认新增卡片数与媒体数。
3. 学习：点牌组 → 音量下翻面 → 音量下评「良好」；检查下一张。
4. 浏览：学习页右上「卡片列表」→ 音量键翻页 → 点卡片 → 返回。
5. 统计：底部「统计」→ 音量键翻到第 2 页。
6. 显示：底部「设置」→ 18/22/26、黑字白底/白字黑底、三档对比度、整屏刷新。
7. 长按音量键、到第一页/最后一页再按，确认没有系统音量面板或连续评分。

## 未验证 / 遗留

1. **物理残影未专项量化**：本次只确认整屏刷新能清残影；连续翻 100 页、不同字号/对比度下的残影累积需专项测试。
2. **其它设备**：只验证 InkPad X 一台；6 寸小屏、Android 9–15、arm64 机型仍需覆盖。
3. **厂商刷新接口**：未接 Swtcon/EPD 私有接口，标准 API 的全刷效果在这台机上可用，但不保证所有厂商。
4. **点击延迟**：未用高速相机/仪器测量，只有手工操作观感。

## 2026-11-18 后续 UI 调整

用户反馈 10 寸 + 26sp 下菜单/顶栏字号偏小、整体偏紧，且不需要配色/反色。调整后：

- 固定白底黑字，删除反色/配色设置；系统栏固定纸色。
- `InkText`、标题、导航、按钮、评分、分页、设置选项全部按 `bodySize/18` 缩放；
  18sp 系数为 1，小屏版式不变。
- 顶栏/导航/列表行/按钮/评分条高度、页边距、设置/统计间距同步放大。
- 设置选中项改为 2dp 粗框 + 圆点 + 加粗，不再黑底反白。
- 26sp 每页 5 条（10 寸 1208dp）；6 寸等小屏大字号自适应降为 3 条。
- 设置页新增语言选项：跟随系统 / 简体中文 / English；切换后重建 Activity，固定语言不随系统变化。

26sp 版式的首页、设置、学习问题/答案面、统计（含英文居中）截图不随仓库分发。

## 2026-11-18 多语言与细节调整

- UI 文案全部走 `values/`（英文默认）与 `values-zh/`（简体中文），默认跟随系统；
  rslib `preferred_langs` 也改为系统语言。英文模拟器实测首页/统计/设置标签正确。
- 学习页删除了顶栏下「音量↓翻面/良好 ↑重来」的拥挤提示，只保留余量。
- 卡片正文与顶栏分隔线之间留白从 8dp 增至 24dp（26sp 时约 34.5dp）。
- 卡片题目/答案分隔线从 2dp 实心墨色改为 1dp、55% 墨色；`<hr>` 与伪元素线同步。
- 统计页键值行上下留白 11→14dp、指标格 12→16dp；2×2 指标格内文字改为水平/垂直居中，
  不再贴左右列之间的竖线。
